# duoqing-net-check

Open-source network diagnostics tool for developers, by 多情 (wwu077957-byte).

开源网络检测工具：查 IP / 归属地 / 运营商、测延迟与上下行速度、
并行检测 AI 应用、社交、流媒体与国内站点的连通性，帮开发者判断
当前线路能不能正常访问开发工具。

Live demo: https://duoqingping.pages.dev
Source: single static HTML file (`index.html`), no build step, no backend.
